# Momentum 4 Control

Неофициальное приложение для управления Sennheiser Momentum 4 по Classic
Bluetooth SPP (RFCOMM) и протоколу GAIA3.

Поддерживаются Windows и macOS.

## Возможности

- Поиск сопряжённых Bluetooth-устройств и подключение к Momentum 4.
- ANC: Adaptive, Custom, Comfort и Off.
- Anti-Wind: Off, Max и Auto.
- Настройка прозрачности в Custom.
- Desktop-приложение Electron с Python-мостом Bluetooth.
- Трей с переключением режимов и применением профилей.
- Сохранение, переименование и удаление профилей настроек.
- Автоподключение и восстановление после сна (включаются в настройках).
- Заряд батареи и версия прошивки, если наушники возвращают эти данные.
- Экспорт диагностического журнала с версией приложения и скрытыми Bluetooth-адресами.

## Требования для разработки

- Python 3.10+ и [uv](https://docs.astral.sh/uv/).
- Node.js 18+ и npm для Electron UI.
- Сопряжённые с компьютером Momentum 4.

Готовые standalone-релизы уже содержат Python-мост. Пользователям Windows и
macOS не нужны Python и `uv`.

## Быстрый старт

Установите зависимости Python-моста и запустите desktop-приложение:

```bash
uv sync
cd ui
npm ci
npm run dev
```

## Desktop UI

```bash
cd ui
npm ci
npm run dev
```

Electron запускает `bridge.py` автоматически. В окне приложения выберите
наушники, подключитесь и настройте режимы.

Ползунок прозрачности поддерживает стрелки, Home и End. Удержание клавиши меняет
предварительное значение; отпускание клавиши или уход с ползунка применяет его.

На вкладке «Приложение» можно включить автоподключение к последним успешно
подключённым наушникам и закрытие окна в трей. Обе настройки по умолчанию
выключены. Ручное отключение или отмена останавливают автоматические попытки
до следующего подключения, повторного включения настройки или перезапуска
приложения. Полный выход доступен через меню трея.

Профили «Работа», «Улица» и «Транспорт» можно дополнить собственными.
Для сохранения профиля задайте название при подключённых наушниках;
сохраняются подтверждённые устройством настройки. Изменение профиля не
применяется автоматически к наушникам. Диагностика экспортируется через
диалог сохранения на отдельной вкладке.

Одновременно работает один экземпляр приложения. Повторный запуск открывает
существующее окно. После сбоя интерфейс перезагружается с сохранением ручного
отключения в текущем сеансе; повторные сбои закрывают приложение с сообщением.

Проверки: `python -m unittest discover -s tests -v` из корня, а из `ui`:
`npm run typecheck`, `npm run test:desktop`, `npm run test:ui`.
`npm run test:smoke` проверяет настоящий запуск Electron/Python, повторный запуск,
восстановление после сбоя интерфейса и закрытие в трей с отдельными настройками.

## Standalone-сборки

Сборка должна выполняться на целевой ОС: PyInstaller не собирает macOS-бинарник
на Windows и наоборот.

### Windows

```powershell
cd ui
npm ci
npm run dist:win
```

Артефакты: `ui/release/*.exe`.

GitHub Actions запускает тесты моста и проверки UI для каждого push и pull
request. При отправке тега вида `v*` дополнительно собираются native-артефакты
для Windows и macOS (`arm64`, `x64` и universal) и публикуются в GitHub Release.

### macOS

На Mac установите `uv` и Node.js, затем:

```bash
uv sync
cd ui
npm ci
npm run dist:mac
```

Артефакты: `ui/release/*.dmg` и `ui/release/*.zip`.

Для Apple Silicon собирайте на Apple Silicon Mac, для Intel - на Intel Mac.
macOS может показать предупреждение при запуске, пока приложение не подписано и
не notarized Apple.

Universal-сборка в CI содержит отдельные Python-мосты для arm64 и x64 и выбирает
нужный при запуске. Исполняемые файлы PyInstaller остаются отдельными, чтобы
сохранить встроенные архивы. При сборке релиза проверяются запуск моста и команды
JSONL без подключённых наушников.

## Технически

Momentum 4 использует GAIA3 с vendor `0x0495` и RFCOMM-сервисом
`a2129ff3-081b-4c45-8afe-469d9c4842ec`.

- `bridge.py` - JSON Lines-мост для Electron.
- `gaia_transport.py` - SPP-транспорт: WinRT на Windows и IOBluetooth на macOS.

## Предупреждение

Проект не связан с Sennheiser. Протокол восстановлен эмпирически и может
отличаться между версиями прошивки. Используйте на свой страх и риск.
